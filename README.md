# Тише

Мобильное офлайн-веб-приложение для пеших маршрутов по Петроградскому, Центральному, Василеостровскому и Адмиралтейскому районам Санкт-Петербурга. Приложение сравнивает быстрый, комфортный и самый тихий маршруты с учётом расчётного транспортного шума, зелёных зон и проходных дворов.

Данные карты: участники OpenStreetMap, лицензия ODbL.
