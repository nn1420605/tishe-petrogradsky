«Тише» — тайловая офлайн-карта Петроградского района.

Карта разделена на 341 квадрат для каждого из двух слоёв: подложка и акустическое загрязнение. Подготовлено пять уровней детализации. Во время движения браузер показывает только видимые тайлы; динамически рисуются лишь маршрут и метки.

Источник геометрии: участники OpenStreetMap, лицензия ODbL. Граница: relation 1114905.
